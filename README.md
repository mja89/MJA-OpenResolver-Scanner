# MJA OpenResolver Scanner

A high-performance Open DNS Resolver Scanner for:

- Android (Termux)
- Linux
- Windows

## Features

- Async DNS Scanner
- Batch Scan
- Resume Scan
- Smart Sampling
- Memory Friendly
- Dashboard
- CSV Report
- client_resolvers.txt Output
- Adaptive Workers
- Adaptive Timeout
